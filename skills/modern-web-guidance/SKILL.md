# Modern Web & Clean Frontend Skill

Boas práticas de React moderno, Tailwind CSS, layouts responsivos flexíveis, acessibilidade (WCAG AA) e performance de renderização.

## Diretrizes Fundamentais
1. **Layouts Flexíveis Sem Vazio**: Utilize sempre contêineres `w-full min-w-0 flex-1` para evitar áreas vazias não redimensionáveis em resoluções widescreen.
2. **Gerenciamento de Estados**: Isole efeitos colaterais e mantenha componentes puros com re-renderizações controladas.
3. **Consistência Visual**: Siga o design system oficial do Tellus com tokens de cores e bordas semânticas.
