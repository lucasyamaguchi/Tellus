## 📝 Dados necessários para personalização

Para eu preencher os entregáveis com precisão, me informe (não precisa ser tudo de uma vez):

1. **Experiência** — anos de experiência; empresas/cargos recentes (max 3–4, com datas)
2. **Stack real** — seu nível real em: Snowflake, Databricks, dbt, Azure, SQL, Python, Airflow (ótimo/bom/médio)
3. **Projetos de IA** — experiências com LLMs, RAG, agentes, embeddings, vector DB (produção ou POC; detalhes)
4. **Métricas fortes** — números que você pode comprovar (ex.: "-40% custo", "SLA 2h", "TB/dia", "redução de alucinação")
5. **Certificações** — SnowPro, Databricks, DP-203, AI-102, dbt, etc.
6. **Inglês** — nível
7. **Objetivo salarial / disponibilidade** — para a conversa com RH (opcional)
8. **LinkedIn/GitHub/portfólio** — links para incluir

> 💡 Quanto mais dados reais você fornecer, mais forte e crível fica a candidatura. Métricas aproximadas com "~" valem mais do que nenhuma métrica — desde que você consiga sustentá-las em entrevista.
